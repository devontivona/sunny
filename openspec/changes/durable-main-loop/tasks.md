## 2. Per-thread conversational workflow

- [x] 2.1 Add a `DurableAgent`-based conversational workflow (`workflows/`) that builds the agent from the shared prompt/tools and runs `while (true) { agent.stream(...); await hook }`, one run per thread — `workflows/conversation.ts:runConversation` (keep-alive per thread, D1)
- [x] 2.2 Steer hook + mid-turn folding (from task 1.3) — **REWORKED after live debugging.** First attempt used the docs' `hook.then(e => queue.push(e))` listener; WDK matches hook payloads to pending consumers FIFO (`workflow/hook.js`), so a listener left armed across the between-turn `await hook` ate the next message's payload and `await hook` never resolved (turns 2+ parked — confirmed via DB: run stuck `running`, flat step count). Fix: (a) BARE `await hook` as the hook's SOLE consumer between turns + an inner "drain all unanswered" loop; (b) mid-turn STEERING without a second hook consumer — `prepareStep` reads newly-arrived messages from the store (`store.unansweredSteers`, excluding window+folded ids) inside a `'use step'` (`loadSteers`) and folds them into the in-flight turn's next step. `prepareStep` runs in the agent's orchestration loop (re-run on replay), so the step read is deterministic. Folded ids are marked in `markAnswered`, so a folded message isn't re-answered. This also fixes the >window-size pileup edge (`unansweredSteers` returns out-of-window unprocessed too). **Op note:** deploying changed durable-workflow code while a run is parked causes `ReplayDivergenceError` → that run fails (acceptable for testing; relevant to cutover).
- [x] 2.3 Implement `send_message` as a `'use step'` REST send by threadId via `adapter.postMessage`, memoized so a replay does not re-send — `sendStep` (`gateway.send` with `persist:false`)
- [x] 2.4 Preserve the D-MG8 output model inside the workflow: send_message-only voice, delivery-recovery pass, `stay_silent`; persist one enriched UIMessage row per turn (D-MG9) — `finalizeTurn` (classify → `recoverDelivery` step → `appendTurnStep`); idempotency via `markAnswered` watermark
- [x] 2.5 Pass `getWritable<UIMessageChunk>()` for the run output stream and `experimental_telemetry` with the per-thread `langfuseSessionId` grouping preserved — `preventClose:true` keeps the run stream open across turns; `langfuseSessionId = threadId`
