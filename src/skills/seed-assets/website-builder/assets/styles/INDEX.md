# Design styles

One line per style. Read the full reference (`assets/styles/<id>.md`) only for the one you choose.

- **sunglow** — Light, warm parchment. Off-white canvas + sand cards, monochrome pill controls, light display headlines (DM Sans 300), color only as decorative gradient orbs. Calm, premium, editorial. Good for: explainers, product/marketing one-pagers, polished reports that should feel approachable.
- **terminal** — Dark TUI. GitHub Dark palette, a single monospace size (JetBrains Mono) on a 24px grid, links not buttons, no shadows/borders/radii. Technical, dense, precise. Good for: dev-facing docs, status/system reports, anything that should read as a terminal.
